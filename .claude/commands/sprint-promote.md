# /sprint promote — Open Main-Merge PR

PM(스프린트 driver) 전용. 모든 AC가 각 owner에 의해 confirm된 후, sprint 브랜치에서 main으로의 머지 PR을 자동 생성한다. **실제 머지는 사람이 GitHub UI에서**.

---

## INVARIANT RULES

1. 실행자는 `sprint.driver_registered`에 기록된 driver와 동일해야 한다 (`VIBE_DRIVER`)
2. `sprint.fully_reviewed` 이벤트가 존재해야 한다 (= 모든 AC owner-confirmed)
3. 현재 브랜치는 sprint 브랜치(`sprint/<N>-...`)여야 한다
4. 머지는 사람 손으로만 — 이 커맨드는 PR 생성까지만 수행
5. 모든 커밋은 `Vibe-Driver` trailer를 가져야 한다 (Phase 5에서 이미 검증되었으나 재확인)

---

## Steps

### 1. Pre-flight

```bash
bash .claude/bin/audit-verify.sh --quiet
BRANCH=$(git symbolic-ref --short HEAD)
case "$BRANCH" in
  sprint/*) ;;
  *) echo "[promote] current branch is not a sprint branch: $BRANCH"; exit 1 ;;
esac
SPRINT=$(echo "$BRANCH" | sed -E 's|^sprint/([0-9]+).*|\1|')

# Verify caller is the driver
RECORDED_DRIVER=$(jq -r --arg s "$SPRINT" '
  select(.event=="sprint.driver_registered" and (.sprint|tostring)==$s) | .driver
' .audit/events.jsonl | tail -1)
if [[ "$VIBE_DRIVER" != "$RECORDED_DRIVER" ]]; then
  echo "[promote] only the sprint driver ($RECORDED_DRIVER) may promote. You are: $VIBE_DRIVER"
  exit 1
fi
```

### 2. Ownership / confirmation gate

```bash
bash .claude/bin/ac-ownership-check.sh matrix "$SPRINT"
if ! bash .claude/bin/ac-ownership-check.sh sprint-ready "$SPRINT"; then
  echo "[promote] not all ACs are confirmed by their owners — refuse"
  exit 1
fi
```

### 3. Trailer audit (defense in depth)

```bash
MISSING=$(git log --format='%H %s' "main..HEAD" | while read sha rest; do
  git log -1 --format='%B' "$sha" | grep -q '^Vibe-Driver:' || echo "$sha $rest"
done)
[ -n "$MISSING" ] && { echo "[promote] commits without Vibe-Driver:"; echo "$MISSING"; exit 1; }
```

### 4. Generate PR body — reviewer matrix + audit summary

```bash
SUMMARY=$(bash .claude/bin/ac-ownership-check.sh matrix "$SPRINT")
CONTRIB=$(git log "main..HEAD" --format='%(trailers:key=Vibe-Committer,valueonly,separator=%x09)' \
          | sort | uniq -c | sort -rn)
DIFFSTAT=$(git diff --shortstat "main..HEAD")
HEAD_HASH=$(jq -r 'select(.event)' .audit/events.jsonl | tail -1 | jq -r .this_hash)

cat > /tmp/promote-body.md <<EOF
## Sprint $SPRINT — Promote to main

**Branch**: \`$BRANCH\`
**Driver (PM)**: $VIBE_DRIVER
**Audit head**: \`${HEAD_HASH:0:16}...\`

### AC Ownership & Confirmation

\`\`\`
$SUMMARY
\`\`\`

### Contributors (by commit count)

\`\`\`
$CONTRIB
\`\`\`

### Diff

\`\`\`
$DIFFSTAT
\`\`\`

### Review Packets

Each AC has a packet at \`.sprint-reports/sprint-$SPRINT/AC-<id>.md\` with:
보고서 / 구현내용 / 기능명세 / 코드명세.

### Audit Trail

\`bash .claude/bin/audit-verify.sh\` passes. Chain integrity verified.

---
🤖 Generated by /sprint promote
EOF
```

### 5. Create PR (NOT merge)

```bash
PR_URL=$(gh pr create \
  --base main \
  --head "$BRANCH" \
  --title "Sprint $SPRINT — $(grep -m1 '^# ' roadmap.md | sed 's/^# //') (driver: ${VIBE_DRIVER%%<*})" \
  --body-file /tmp/promote-body.md \
  --label "sprint:$SPRINT" --label "needs-pm-final-review" \
  | tail -1)

bash .claude/bin/audit-append.sh --git-sync '{
  "event":"sprint.promote_pr_opened",
  "sprint":"'"$SPRINT"'",
  "branch":"'"$BRANCH"'",
  "pr_url":"'"$PR_URL"'",
  "opened_by":"'"$VIBE_DRIVER"'"
}'

cat <<EOF

═══════════════════════════════════════════════════════
✅ Main-merge PR opened:
   $PR_URL

Next: PM reviews on GitHub and merges manually.
After merge, run:
  bash .claude/bin/audit-attest.sh --label "sprint-$SPRINT"
═══════════════════════════════════════════════════════
EOF
```

---

## Failure modes

| Situation | Behavior |
|-----------|----------|
| Caller ≠ recorded driver | refuse |
| Any AC not confirmed | refuse, print matrix |
| Any commit missing Vibe-Driver | refuse, print SHAs |
| `gh` not authenticated | refuse with instruction |
| PR already exists for this branch | print existing URL, do not duplicate |
